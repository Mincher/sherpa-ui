Tier-1 support queue view. Built from the list-view pattern returned by get_pattern. Tabs scope the ticket grid; the filter bar exposes preset “severity” and “channel” filters the MCP server recommended for support data. Adding a new ticket pops a dialog and fires a toast on save.

The tab is rendered eagerly (data-load-mode="eager" is the default). When you flip the MCP data-load-mode to lazy, the grid would be populated the first time the tab becomes active, on a tab-load event.
