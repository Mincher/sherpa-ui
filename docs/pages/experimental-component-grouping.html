Experimental

The .grouped-component CSS utility and the <sherpa-container-group> web component both merge adjacent elements into a single visual unit by collapsing their borders and border-radii. Use .grouped-component for small control groupings (buttons, inputs); use <sherpa-container-group> for grouping dashboard tiles inside a <sherpa-layout-grid>.

Wrap components in .grouped-component to merge them horizontally. The wrapper becomes an inline-flex container with shared borders and no gap.

HTML 
<div class="grouped-component">
  <sherpa-button data-variant="secondary" data-label="First"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Second"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Third"></sherpa-button>
</div>

Add data-direction="vertical" to stack components vertically into a single bordered unit.

HTML 
<div class="grouped-component" data-direction="vertical">
  <sherpa-button data-variant="secondary" data-label="First"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Second"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Third"></sherpa-button>
</div>

A tile group is a <sherpa-container-group> web component holding an optional <sherpa-container-header> title row (spans all columns) followed by headerless <sherpa-container> tiles. It sits as a direct child of <sherpa-layout-grid> and adopts the parent's responsive 12 / 6 / 3 column tracks via grid-template-columns: subgrid — so tiles' data-col-span values line up flush with peers in the outer grid and reflow automatically at every breakpoint. The first tile's own <sherpa-container-header> serves as the group title; subsequent tiles' headers are visually muted (header bands still reserve their natural height so content baselines align across rows) via a cascading data-group-position attribute managed by the group.

HTML 
<sherpa-layout-grid>
  <sherpa-container-group data-col-span="12">
    <!-- The first tile's  serves as the group title.
         Follower tiles keep their own headers, but the group visually mutes
         their content while preserving header-band height so every tile's
         metric body aligns across rows. -->
    <sherpa-container data-col-span="6">
      <sherpa-container-header slot="header" data-title="KPIs" data-menu-button="true"></sherpa-container-header>
      <sherpa-metric data-label="Revenue" value="$1.24M" data-trend="up" data-delta="+8.3%"></sherpa-metric>
    </sherpa-container>
    <sherpa-container data-col-span="3">
      <sherpa-container-header slot="header" data-title="Users" data-menu-button="true"></sherpa-container-header>
      <sherpa-metric data-label="Users" value="4,821" data-trend="up" data-delta="+12%"></sherpa-metric>
    </sherpa-container>
    <!-- repeat with mixed data-col-span values from {2, 3, 4, 6, 8, 9, 12} -->
  </sherpa-container-group>
</sherpa-layout-grid>

<!-- The wrapper adopts the layout grid's responsive 12 / 6 / 3 column
     tracks via `grid-template-columns: subgrid`. The first tile's header
     acts as the group title; per-tile `data-row-span` (2..6) is supported
     for tall charts. -->
