Experimental

The .grouped CSS utility merges adjacent components into a single visual unit by collapsing their borders and border-radii. Works with any Sherpa component. Supports three layouts: row (default), column (stacked), and grid.

Wrap components in .grouped to merge them horizontally. The wrapper becomes an inline-flex container with shared borders and no gap.

HTML 
<div class="grouped">
  <sherpa-button data-variant="secondary" data-label="First"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Second"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Third"></sherpa-button>
</div>

Add data-direction="vertical" to stack components vertically into a single bordered unit.

HTML 
<div class="grouped" data-direction="vertical">
  <sherpa-button data-variant="secondary" data-label="First"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Second"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Third"></sherpa-button>
</div>

A grouped grid is a <div class="grouped" data-layout-grid> wrapper holding two rows: a <sherpa-header> in row 1 (spans all columns; carries the group title and overflow menu), then headerless <sherpa-container> tiles in the rows below. The wrapper sits as a direct child of <sherpa-layout-grid> and adopts its responsive 12 / 6 / 3 column tracks via grid-template-columns: subgrid — so tiles' data-col-span values line up flush with peers in the outer grid and reflow automatically at every breakpoint. The wrapper uses display: grid-lanes so sub-containers of differing heights pack into the column tracks masonry-style — no prescribed row count, no forced equal-height cells. Sub-container headers are omitted; only the group header controls the whole tile.

HTML 
<sherpa-layout-grid>
  <div class="grouped" data-layout-grid>
    <!-- Row 1: group header (spans all subgrid columns automatically) -->
    <sherpa-header data-title="KPIs" data-menu-button="true"></sherpa-header>

    <!-- Remaining children: headerless sub-containers, sized via data-col-span -->
    <sherpa-container data-col-span="6">
      <sherpa-metric data-label="Revenue" value="$1.24M" data-trend="up" data-delta="+8.3%"></sherpa-metric>
    </sherpa-container>
    <!-- repeat with mixed data-col-span values from {3, 6, 9, 12} -->
  </div>
</sherpa-layout-grid>

<!-- The wrapper adopts the layout grid's responsive 12 / 6 / 3 column
     tracks via `grid-template-columns: subgrid`, and uses
     `display: grid-lanes` so children of varying heights pack into the
     column tracks masonry-style. The first child <sherpa-header> takes
     a full-width row (rule: `[data-layout-grid] > sherpa-header { grid-column: 1 / -1 }`);
     remaining children fall onto subsequent rows. -->
