Experimental

A CSS utility class that progressively hides flex children as a container shrinks. Apply class="flex-truncate" to any flex container. Children are clip-masked when they would fall below their configured minimum size — no JavaScript required. Works in both row (default) and column directions.

Children are hidden when the container narrows past their minimum width (default 180 px; override with data-min-child-width). Drag the right edge of the preview to test.

HTML 
<div class="flex-truncate">
  <sherpa-metric data-label="Revenue"  value="$1.24M" data-trend="up"   data-delta="+8.3%"></sherpa-metric>
  <sherpa-metric data-label="Users"    value="4,821"  data-trend="up"   data-delta="+12%"></sherpa-metric>
  <sherpa-metric data-label="Uptime"   value="99.9%"  data-trend="flat" data-status="success"></sherpa-metric>
  <sherpa-metric data-label="Response" value="42ms"   data-trend="down" data-delta="−6ms"></sherpa-metric>
  <sherpa-metric data-label="Errors"   value="0.02%"  data-trend="down" data-status="success"></sherpa-metric>
</div>

Set data-direction="column" to stack children vertically. Give the container a fixed height; children that cannot fit their minimum height (data-min-child-height) are hidden. Drag the bottom edge of the preview to test.

HTML 
<div class="flex-truncate"
     data-direction="column"
     data-min-child-height="64px"
     style="height: 300px;">
  <sherpa-metric data-label="Revenue"  value="$1.24M" data-trend="up"   data-delta="+8.3%"></sherpa-metric>
  <sherpa-metric data-label="Users"    value="4,821"  data-trend="up"   data-delta="+12%"></sherpa-metric>
  <sherpa-metric data-label="Uptime"   value="99.9%"  data-trend="flat" data-status="success"></sherpa-metric>
  <sherpa-metric data-label="Response" value="42ms"   data-trend="down" data-delta="−6ms"></sherpa-metric>
  <sherpa-metric data-label="Errors"   value="0.02%"  data-trend="down" data-status="success"></sherpa-metric>
</div>
