Flex Truncate

A CSS utility class that progressively hides flex children as a container shrinks. Apply .flex-truncate to any flex container. Children are clip-masked when they would fall below their configured minimum size. Works in row (default) and column directions. Drag the resize handles to see it in action.

Row — resize width

Default mode. Children are hidden when the container is too narrow to fit them at their minimum width (default 180 px; override with data-min-child-width). Drag the right edge of the preview to test. 

<div class="flex-truncate">
  <sherpa-metric data-label="Total Revenue" value="$1.24M" data-trend="up"   data-delta="+8.3%"></sherpa-metric>
  <sherpa-metric data-label="Active Users"  value="4,821"  data-trend="up"   data-delta="+12%"></sherpa-metric>
  <sherpa-metric data-label="Uptime"        value="99.9%"  data-trend="flat" data-status="success"></sherpa-metric>
  <sherpa-metric data-label="Avg Response"  value="42ms"   data-trend="down" data-delta="−6ms"></sherpa-metric>
  <sherpa-metric data-label="Error Rate"    value="0.02%"  data-trend="down" data-status="success"></sherpa-metric>
</div>

Column — resize height

Set data-direction="column" to stack children vertically. Give the container a fixed height; children that can’t fit their minimum height (data-min-child-height) are hidden. Drag the bottom edge of the preview to test. 

<div class="flex-truncate"
     data-direction="column"
     data-min-child-height="100px"
     style="height: 540px;">
  <sherpa-metric data-label="Total Revenue" value="$1.24M" data-trend="up"   data-delta="+8.3%"></sherpa-metric>
  <sherpa-metric data-label="Active Users"  value="4,821"  data-trend="up"   data-delta="+12%"></sherpa-metric>
  <sherpa-metric data-label="Uptime"        value="99.9%"  data-trend="flat" data-status="success"></sherpa-metric>
  <sherpa-metric data-label="Avg Response"  value="42ms"   data-trend="down" data-delta="−6ms"></sherpa-metric>
  <sherpa-metric data-label="Error Rate"    value="0.02%"  data-trend="down" data-status="success"></sherpa-metric>
</div>
