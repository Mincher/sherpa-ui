Experimental

Grouped

The .grouped CSS utility merges adjacent Sherpa components into a single visual unit by collapsing their individual borders and border-radii. Works with any component. Supports three arrangements: row (default), column, and grid.

Row

Wrap components in .grouped to merge them horizontally. The container becomes an inline-flex row with shared borders and no gap. 

<div class="grouped">
  <sherpa-button data-variant="secondary" data-label="First"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Second"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Third"></sherpa-button>
</div>

Column

Add style="flex-direction: column" to stack components vertically into a single bordered unit. 

<div class="grouped" style="flex-direction: column;">
  <sherpa-button data-variant="secondary" data-label="First"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Second"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Third"></sherpa-button>
</div>

Grid

Add data-layout-grid to switch to a CSS grid layout. Use --_cg-columns to control the column count (defaults to 3). Toggle the button below to compare grouped and ungrouped states. 

<!-- ungrouped -->
<div class="kpi-wrapper">
  <sherpa-container><sherpa-metric data-label="..." value="..."></sherpa-metric></sherpa-container>
  ...
</div>

<!-- grouped (add .grouped + data-layout-grid; JS toggles these) -->
<div class="kpi-wrapper grouped" data-layout-grid style="--_cg-columns: 3;">
  <sherpa-container><sherpa-metric data-label="..." value="..."></sherpa-metric></sherpa-container>
  ...
</div>
