Experimental

Grouped

The .grouped-component CSS utility and the <sherpa-container-group> web component both merge adjacent elements into a single visual unit by collapsing their individual borders and border-radii. Use the utility class for small control groupings (buttons, inputs); use the web component for grouping dashboard tiles in a layout grid.

Row

Wrap components in .grouped-component to merge them horizontally. The container becomes an inline-flex row with shared borders and no gap. 

<div class="grouped-component">
  <sherpa-button data-variant="secondary" data-label="First"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Second"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Third"></sherpa-button>
</div>

Column

Add data-direction="vertical" to stack components vertically into a single bordered unit. 

<div class="grouped-component" data-direction="vertical">
  <sherpa-button data-variant="secondary" data-label="First"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Second"></sherpa-button>
  <sherpa-button data-variant="secondary" data-label="Third"></sherpa-button>
</div>

Dashboard tile group

Wrap a set of <sherpa-container> tiles in a <sherpa-container-group> web component to merge them into a single bordered unit. The group adopts the parent layout grid's column tracks via subgrid; per-tile data-col-span still works. Toggle the button below to compare grouped and ungrouped states. 

<!-- ungrouped — plain grid of independent tiles -->
<div class="kpi-wrapper">
  <sherpa-container><sherpa-metric data-label="..." value="..."></sherpa-metric></sherpa-container>
  ...
</div>

<!-- grouped — wrap the tiles in a sherpa-container-group web component -->
<sherpa-container-group>
  <sherpa-container><sherpa-metric data-label="..." value="..."></sherpa-metric></sherpa-container>
  ...
</sherpa-container-group>
